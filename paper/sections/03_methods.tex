\section{Spatial continuation}
\label{sec:methods}
Let $\mathcal D={(x_i,y_i)}_{i=1}^n$ be the training sample and $f_\theta$ the original network. During training, we modify the spatial resolution and, when filtering is used, the filter scales of the inner layers. We describe these choices by a state $s$ and write $f_{\theta,s}$ for the corresponding network, with loss
\begin{equation}
L_s(\theta)=\frac1n\sum_{i=1}^n\ell(f_{\theta,s}(x_i),y_i),
\qquad f_{\theta,s_\star}=f_\theta,
\label{eq:family}
\end{equation}
where $\ell$ is cross-entropy and the final state $s_\star$ restores the original network. We train for a fixed number of stochastic gradient updates at each state, then move to the next while keeping the weights and optimizer state. This gradually recovers the original training problem without requiring each intermediate problem to be solved exactly. We use ``continuation'' to describe this progression. Since resolution changes are discrete and max-pooling is nonsmooth, we do not claim to follow a smooth path of minimizers.

\subsection{Resolution reduction}
Here we reduce the spatial size of a feature map $h\in\R^{C\times H\times W}$ using adaptive max-pooling, which keeps the largest value in each window, separately for each channel:
\begin{equation}
[R_{r_h,r_w}(h)]_{c,i,j}=\max_{(p,q)\in B_{i,j}}h_{c,p,q}.
\label{eq:pool}
\end{equation}
Each window $B_{i,j}$ contains the positions of the original map summarized by the output value at $(i,j)$. For example, reducing a $32\times32$ map to $16\times16$ amounts to taking the maximum in each $2\times2$ block. For other size changes, the windows can overlap their exact definition is given in Appendix~\ref{app:sites}. In the selected ResNet-20, we apply this operation to the full output of the second residual block, after the residual addition and final ReLU. The resulting map feeds both branches of the next block. Its side length increases from 16 during epochs 0--5 to 24 during epochs 6--11, then returns to 32 for epochs 12--29.

The following layers process these smaller maps directly, without first upsampling them. Global average pooling ensures that the classifier still receives an input of the same dimension, and all trainable parameter shapes remain unchanged. Although this operation reduces spatial resolution, it does so by retaining local maxima and is therefore not a linear low-pass projection.


\subsection{Gaussian filtering}
For these methods, we smooth each feature map $h_j$ by averaging neighboring values with Gaussian weights as follows
\begin{equation}
h_{j,s}=G_{\sigma_j(s)}*h_j,
\label{eq:gaussian}
\end{equation}
where $\sigma_j(s)$ controls the amount of smoothing. The filter is applied independently to each channel. The filter introduces no trainable parameters, and setting $\sigma_j(s)=0$ leaves the feature map unchanged. In the reference ResNet-20, the Gaussian-only method applies the filter after the initial ReLU and after the final ReLU of each residual block, giving ten filtering sites. The combined method instead filters the outputs of all 19 convolutions, before BatchNorm.

Both methods use a base scale $g(e)$ that decreases from $1$ to $0.3$ in stages lasting three epochs each, with filtering removed from epoch 21 onward. For Gaussian-only, the filter scale is simply $g(e)$; in the combined method, it is also adjusted to the resolution schedule, as described below.

The combined procedure follows the same resolution schedule as R, with one additional rule linking the Gaussian scale to the resolution. If $r(e)$ is the side length chosen at epoch $e$, its filter scale is
\begin{equation}
\sigma_j(e)=g(e)\frac{r(e)}{32}
\quad\text{at all 19 filtering sites}.
\label{eq:coupling}
\end{equation}
The same factor is applied even at the five sites before the reduction, where the maps remain $32\times32$. As a result, an increase in resolution can temporarily increase the effective blur, even though $g(e)$ decreases (Appendix~\ref{app:schedules}).

Together with the different filtering locations described above, this means that RG does more than simply add the Gaussian-only procedure to R. We therefore compare three complete training procedures, rather than independently switching the same two interventions on and off. All three end at the original resolution with the added operations disabled.
