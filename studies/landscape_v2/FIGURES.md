# Figure index (landscape study v2)

All figures are in `figures/` as PDF and PNG, generated by
`py -m landscape_v2.analyze`. The underlying numbers are in `tables/`.

Common conventions:

- **Runs:** 20 new runs, four methods × seeds 0–4, paired within each seed.
- **Probes:** 1,000 class-balanced images, unless a figure says otherwise.
- **Final state:** full resolution with no filter.
- **Surfaces:** every vertex is a measured point.

## Recommended reading order

### 1. Final-solution sensitivity (primary result)

| file | caption |
|---|---|
| `S1_sensitivity_by_amplitude` | Symmetric sensitivity S̄(ε) of the epoch-30 solutions, averaged over 20 matched relative filter-wise directions within each seed. Dots are seeds; lines are the mean ± SD across the five seeds; saved vs recalibrated BatchNorm; train vs test probe; log scale. |
| `S2_paired_differences` | S̄(method) − S̄(plain) within each seed. Resolution-only and combined are below 0 in every seed with saved statistics and on the recalibrated training probe. Gaussian-only is above 0 in every seed once BatchNorm is recalibrated. |
| `S3_direction_spread` | Spread over the 20 directions for each seed, test probe, ε = 0.10 and 0.25, both policies. |
| `V1_probe_vs_larger_sets` | Prespecified validation points (directions 0–1, ε = 0.10 and 0.25, both signs): the 1,000-image probe values against the 10,000-image training subset and the full test set. |
| `A1_surface3d_absolute_seed0_g41`, `A2_surface3d_centered_seed0_g41` | Prespecified primary surfaces: seed 0, directions 0 and 1, 41×41 grid, recalibrated BatchNorm, final state, absolute and centre-subtracted CE, shared scales per split. These are local slices with matched relative perturbations, not one physical plane. |
| `A1/A2_surface3d_*_seed{1..4}_g21`, `A1/A2_contour_*` | The same surfaces for every other seed at 21×21, with contour companions. |
| `surfaces_interactive.html` | Rotatable seed-0 surfaces. |

### 2. Straight segments

| file | caption |
|---|---|
| `D1_interpolation_segments` | Loss along straight segments between the final solutions of the same seed (51 points, recalibrated BatchNorm), one line per seed. Every segment has a barrier. A straight-line barrier does not establish disconnected basins. |

### 3. Fixed-weight intervention comparisons

| file | caption |
|---|---|
| `F1_fixed_weight_states` | Checkpoints taken at each schedule's first and last transition, evaluated under the state before, the state after, and the final state. Top: centre loss. Bottom: S̄(0.25) around the centre (10 directions, recalibrated BatchNorm). Dots are seeds. |
| `B1_fixed_surface3d_absolute_*`, `B2_fixed_surface3d_centered_*` | Seed-0 surfaces of the same fixed weights under each state, with shared axes and scales. The combined method's states change both components at once. |

### 4. Trajectories (read with the projection limits)

| file | caption |
|---|---|
